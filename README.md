# ChatTranslate

面向 Vencord 桌面端的独立翻译插件：本地识别语种，只自动翻译阅读视窗内的消息，支持上下文批量翻译和草稿预览。

**当前为 0.1.0 开发预览。** 本地语种识别、自动调度和翻译协议可独立测试。支持 Magpie / DeepSeek Flash 本机连接配置；Discord 输入框、实际可见区域和原生 IPC 仍需客户端验收，构建通过不代表已安装。

## 功能

- 本地 fastText WASM 识别，模型随构建打包，运行时不下载模型、不调用识别 API。
- 中英阅读、英文频道、中文频道预设，支持频道覆盖服务器设置、线程继承所属频道。
- 非中文翻译、指定源语言、语言对应表，以及混合消息规则。
- 消息连续可见 1 秒后入队；每批最多 50 条，最多 5 条可见只读上下文计入上限。
- 同频道按时间排序，匿名说话者、可见回复关系和稳定结果 ID。
- 消息悬浮按钮与右键菜单：翻译、选择语言、重新翻译、隐藏。
- 草稿按需翻译、预览、纯文本应用及恢复；不会自动发送。
- 内存缓存、在途控制、字符预算、占位符校验、编辑后拒绝旧译文。
- 本机私密连接配置或自定义 Chat Completions 接口，支持 Magpie / DeepSeek V4 Flash。

## 开发

需要 Node.js 22.18 或更新版本、npm，以及进行 Vencord 验证时使用的 pnpm 11.9.0。

```sh
npm ci --ignore-scripts
npm run check
npm run test:worker
npm run test:native
npm run verify:vencord
```

`npm run build` 生成 `dist/chatTranslate.desktop/`。它包含可复制到 Vencord
`src/userplugins/chatTranslate.desktop/` 的插件源码、核心模块、后台识别线程和许可证。
生成目录无需在 Vencord 项目额外安装 fastText 依赖。`dist/` 不纳入 Git。

`verify:vencord` 在 `.cache/vencord/` 创建独立的固定版本检出，安装其锁定依赖，
检查插件类型并构建桌面版本；不运行安装器，不修改已安装的 Discord。
若已有上游检出，可设置 `VENCORD_SOURCE` 指向该本地仓库，以避免再次下载 Git 历史。

## 配置和使用

1. 按 Vencord 自定义插件流程构建并安装，在设置中启用 ChatTranslate。
2. 默认读取本机连接文件；Magpie 配置见 [接入说明](docs/MAGPIE.md)。若使用其他接口，关闭“使用本机连接配置”，填入完整的 `chat/completions` 地址、模型和密钥。
3. 在服务器或频道右键菜单，或任意消息的“消息翻译”菜单中，选择阅读预设。
4. 全局自动翻译默认关闭。中英/英文范围预设会在该范围开启，中文预设默认关闭。
5. 草稿翻译通过输入栏按钮打开；先预览译文，再应用或复制，发送由你操作。

详细设置见 [默认配置](docs/DEFAULTS.md)，开发结构见 [架构](docs/ARCHITECTURE.md)，
实机检查见 [验收清单](docs/ACCEPTANCE.md)。

## 数据与边界

- 识别在本地后台线程进行。实际翻译会将待译消息和最多 5 条可见上下文发送到你指定的服务。
- 说话者使用批次内匿名编号，服务请求不包含 Discord 作者 ID 或频道 ID。
- 译文不写入服务器，不自动发送消息；内存缓存默认不落盘。
- 本机连接模式仅在原生进程读取私密文件，密钥不进入 Vencord 设置或渲染进程。自定义模式的密钥仍保存在 Vencord 设置中，分享或导出设置前须移除。
- 字符预算不是费用估计，也不等于 token 限额；重启插件后计数重置。首版不提供持久费用账本。
- 50 条是最大批次；长消息按字符预算拆小批，单条超过上限会明确报错，不静默截断。
- 不同兼容接口的上下文长度、参数与结构化输出能力不同，必须测试实际服务。
- 短汉字和短词的语种仍可能不确定；规则保留未知，不宣称百分之百准确。
- 仅桌面端，网页分支和 ELD 切换尚未实现。ELD 保留为后续替换适配器的候选。
- 草稿直接应用暂限当前主频道的纯文本输入框。复杂提及和不兼容编辑器提供复制路径。
