# 中英阅读默认配置

| 项目             | 默认值                                                       |
| ---------------- | ------------------------------------------------------------ |
| 全局自动翻译     | 关闭；选定范围可单独开启                                     |
| 预期语言         | 中文、英语，作为语境，不限制模型输出语言                     |
| 接收目标         | 简体中文；简繁中文默认保留                                   |
| 连续可见时间     | 1000 ms                                                      |
| 每批项目数       | 最多 50，包含上下文                                          |
| 可见只读上下文   | 最多 5 条，优先待译目标                                      |
| 在途请求         | 最多 2 批，手动请求优先                                      |
| 每批原文字符     | 12000                                                        |
| 每日请求内容字符 | 100000，客户端重启重置，包含序列化上下文与重试；不是货币预算 |
| 自动重试         | 最多 2 次；临时错误等待 2 秒、5 秒，可配置 0–3 次            |
| 超时             | 30 秒                                                        |
| 最大输出 token   | 6000，实际服务必须支持该参数和额度                           |
| 翻译服务配置     | 本机私密文件；自定义接口可在设置中切换                       |
| Magpie 模型      | 配置脚本使用 deepseek/deepseek-v4-flash / low                |
| 最短英文长度     | 不设统一门槛                                                 |
| 简短应答跳过表   | 空                                                           |
| 保留交易符号     | ES、NQ、MES、MNQ、VWAP                                       |
| 术语表           | payout -> 出金；drawdown -> 回撤；仅译成中文时使用           |
| 草稿默认目标     | en 英语；留空时中英/英文预设用英语，中文预设用简体中文       |
| 三空格快捷触发   | 关闭；可在插件设置开启                                       |
| 相邻空格间隔     | 最多 500 ms；可配置，使用时限制为 100–2000 ms                |
| 译文样式         | 原生文本；也可选引用、边框、虚线、柔和、强调、底色、模糊     |
| 译文字号／斜体   | 100%／关闭；字号使用时限制为 70–150%                         |
| 本地译文缓存     | 开启；30 天、5000 条、文件最多 10 MiB                        |
| 提及名称         | 本地服务器昵称、显示名、用户名；未知名称使用通用标签         |

中英与英文预设均开启该范围内非中文翻译；中文预设默认关闭自动翻译。
频道设置优先于服务器设置；线程默认继承所属频道。
全局规则可选择非中文、指定语言、语言对应表、全部自然语言。
收到消息的手动翻译不受自动开关或语言白名单限制。
样式、字号、斜体和空格快捷键的变更不重启翻译引擎，不会清空译文缓存。
其他语言规则或服务配置变化会重建引擎。范围变更保留内存译文缓存和当日字符计数；
服务配置变更清空译文缓存。修改内容、目标或术语表会产生新缓存项。
内存缓存最多 1000 项，另有本地持久缓存，默认 5000 项、30 天及 10 MiB。
客户端重启后优先复用有效的消息译文；过期、淘汰、关闭持久缓存、清空或明确重译后可以重新请求。
文件不可用时退回内存和正常翻译路径；清空按钮同时清空内存和本地文件内容。
私密 profile 中的模型改动后应清空缓存；持久文件按实际端点、模型与思考档位隔离。

自动失败只在频道视窗状态汇总。凭证错误暂停；429 等待冷却，手动重试不能绕过。
临时网络错误、超时和 5xx 使用有上限的批量重试，每次重新筛选当前视窗。
超过重试次数暂停新自动请求，恢复后可点击“重试当前视窗”。
缺项／保护符校验失败保留成功项，失败项由汇总按钮手动重试，不分裂成逐条请求。
草稿失败保留原文，不自动重试。

本机 Magpie 接入保持 `low`。2026-10-10 实测 Chat `reasoning_effort: none`
和 Responses `reasoning.effort: none` 仍产生思考 token；没有提供一个声称有效的关闭开关。
“查看翻译状态”显示接口报告的计数；未报告时显示“未提供”，不视为零。

当前的候选分数门槛是开发启发式，尚未用独立大样本校准。
英文短词在中英语境下允许 source=auto 实际翻译；中日共享汉字
且无明确特征时保留未知。不能把分数解释成真实准确率。

字符上限和输出 token 上限分别限制输入规模与输出规模。首版尚未接入
服务商 tokenizer 或自动探测模型上下文长度；不要据此声称不会超过任何模型预算。
